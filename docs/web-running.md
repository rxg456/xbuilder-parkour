# 网页版运行说明

## 环境与文件

- 桌面版 Chrome 或 Edge、稳定网络、可登录的 XBuilder 账号。
- 项目包：仓库根目录的 `parkour-web.xbp`。
- 无需本地安装 Go、XGo、spx 引擎或后端服务；编译与运行由 XBuilder 提供。
- `.xbp` 内部是 ZIP 容器，但请保留扩展名；GitHub 的源码 ZIP 不是可直接打开的项目包。

源码位于 `web-native/`；Go 核心演示和本地
`spx/` v2 实验入口是另外两条运行路径，不应混用。

## 导入与启动

1. 在 GitHub 仓库根目录打开 `parkour-web.xbp`，下载原始文件。
2. 访问 <https://xbuilder.com/>，登录账号；项目新建和打开可能要求登录。
3. 打开项目菜单，选择 `Open project...`，在本地文件选择流程中选择 `.xbp`。
4. 按页面提示进入项目编辑器，确认项目名为 `Squirrel Parkour`，
   精灵列表包含 `Squirrel` 和 `Track`。不要覆盖仍需保留的其他项目。
5. 点击运行按钮，等待游戏区域出现草地背景、松鼠、地面、障碍和计分监视器。
6. 点击游戏区域获得焦点，按空格开始。不要把编辑器文本输入框作为按键焦点。

平台菜单名称可能随版本调整；上述路径以本次导入使用的项目菜单为准。
此前项目地址为 <https://xbuilder.com/editor/rxg456/parkour/sprites/Squirrel/code>，
可能需要项目访问权限，不能代替可下载项目包作为唯一运行方式。

## 操作规则

| 操作 | 待开始 | 运行中 | 结束后 |
| --- | --- | --- | --- |
| 空格 | 开始，不立即跳跃 | 落地时跳跃，空中忽略 | 无动作 |
| 游戏区域点击 | 开始，不立即跳跃 | 落地时跳跃 | 重置到待开始 |
| `R` | 重置 | 重置 | 重置到待开始 |

角色横坐标固定，障碍从右往左移动，速度逐渐增加。
与障碍重叠后结束，画面中的障碍停止推进。
Score 按跑动距离计分，Best 在结束时更新；
`R` 重置当前分数而不清除本次运行会话中的最高分。
停止运行、重新启动或刷新页面后的最高分不保证保留。

## 检查与故障处理

- 看不到角色或计分：确认使用当前包，而非旧候选包；当前视口是 `480×360`。
  如修改了项目配置，检查松鼠初始位置 `(-150, -104)` 及资源绑定。
- 按空格无反应：先点击游戏区域，将焦点从代码编辑器或其他输入框移开。
  第一按开始，第二按才跳跃；结束后先按 `R` 重置。
- 项目无法打开：检查下载的是完整 `.xbp`，不是网页 HTML 或 GitHub 源码 ZIP，
  并确认已登录。保留具体报错供排查。
- 有背景和地面但缺少角色：检查 `Squirrel.spx`、
  `assets/sprites/Squirrel/index.json` 和所有动画造型是否完整导入。
- 暂时无声：检查浏览器静音、系统音量和页面交互授权。
  音效资源已包含在项目中，但声音不是判断逻辑正常运行的唯一依据。
